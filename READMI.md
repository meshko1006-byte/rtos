## Опис проєкту

Цей проєкт демонструє роботу планувальника операційної системи реального часу **FreeRTOS** на базі симулятора для Windows (`WIN32-MSVC`). Програма реалізована у файлі `main_blinky.c` та створює три негармонічні періодичні задачі ($\tau_1, \tau_2, \tau_3$) із різними пріоритетами.

### Що робить проєкт:
1. **Ініціалізація задач:** За допомогою функції `xTaskCreate()` створюються три періодичні задачі з іменами `MEIV_T1`, `MEIV_T2` та `MEIV_T3`.
2. **Імітація обчислень (Busy-loop):** Кожна задача у нескінченному циклі виконує активне навантаження процесора тривалістю $C_i$ мілісекунд за допомогою функції `simulate_busy_work()`, яка відстежує системні тіки через `xTaskGetTickCount()`.
3. **Логування:** На кожній ітерації задача фіксує системний час початку (`Start tick`), час завершення (`Finish tick`) та очікувану тривалість роботи (`Duration`) і виводить ці дані у консоль.
4. **Точна періодичність:** Виклик функції `vTaskDelayUntil()` переводить задачу у стан очікування (Blocked) рівно до початку наступного періоду $T_i$, забезпечуючи мінімальний джитер початку періоду для високопріоритетної задачі та демонструючи механізм витіснення (preemption) для задач нижчого пріоритету.

## Інструкція із запуску проєкту

Для компіляції та запуску проєкту на ОС Windows необхідні встановлені **Git** та **Visual Studio** (з компонентом *Desktop development with C++*).

### Крок 1. Завантаження базового репозиторію FreeRTOS та ядра
Відкрийте термінал (Git Bash або PowerShell) та виконайте клонування офіційного репозиторію FreeRTOS разом із підмодулями ядра:

```bash
git clone https://github.com/FreeRTOS/FreeRTOS.git
cd FreeRTOS
git submodule update --init --recursive
```

*(Якщо потрібно завантажити лише ядро FreeRTOS без сторонніх бібліотек, виконайте команду):*

```bash
git clone https://github.com/FreeRTOS/FreeRTOS-Kernel.git FreeRTOS/Source
```

### Крок 2. Підготовка файлів лабораторної роботи
1. Відкрийте рішення симулятора у Visual Studio за шляхом:
   ```text
   FreeRTOS\Demo\WIN32-MSVC\WIN32.sln
   ```
2. Якщо з'явиться вікно оновлення компілятора (**Retarget Projects**), оберіть доступний *Platform Toolset* та натисніть **OK**.
3. У файлі `main.c` встановіть значення макроса `mainCREATE_SIMPLE_BLINKY_DEMO_ONLY` в `1`:
   ```c
   #define mainCREATE_SIMPLE_BLINKY_DEMO_ONLY 1
   ```
4. Замініть вміст файлу `main_blinky.c` на код із цього репозиторію.

### Крок 3. Компіляція та запуск
Натисніть клавішу **`F5`** (або кнопку **Local Windows Debugger** на верхній панелі Visual Studio). Після успішної збірки відкриється консольне вікно з логами виконання задач у реальному часі:

## Дослідження `configUSE_TIME_SLICING`

Для перевірки роботи планувальника при рівних пріоритетах задач у файлі `FreeRTOSConfig.h` змінюється параметр `configUSE_TIME_SLICING`:

```c
#define configUSE_TIME_SLICING 1 // 1 - увімкнено (Round-Robin), 0 - вимкнено
```

* При `configUSE_TIME_SLICING = 1` задачі рівного пріоритету перемикаються кожного системного тіка (кванта часу), що зменшує затримку старту, але збільшує час до повного завершення ітерації.
* При `configUSE_TIME_SLICING = 0` активна задача виконує свою роботу `simulate_busy_work()` без переривань іншими задачами того ж пріоритету до моменту виклику `vTaskDelayUntil()`.
